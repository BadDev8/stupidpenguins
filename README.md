# Stupid Penguins

I was studying statistics, but it sucks and it isn't real math, so I implemented a penguin classifier from scratch using only numpy/pandas for data manipulation and a rudimental normal distribution regression I also wrote.

For record (even if you should definetely know it) [Kaggle - Palmer penguins](https://www.kaggle.com/datasets/jaeyunju/penguins?resource=download) is the source of the data I used.
